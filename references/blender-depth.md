# Blender 曲面纸张、空间层次与透明通道

这套方法把符纸当作有弯曲、厚度、受光与前后关系的物体。
它适合大量纸阵中的少量近景主体，以及需要导入 AE 的独立透明通道。
示例采用可控的网格和形态键动画；它不是布料物理模拟，也不包含角色原画。

## 先明确交付与坐标

- 决定最终画幅、帧率、总帧数、局部第一帧对应的主时间轴帧号。
- 约定主时间轴从 0 计数，Blender 序列从 1 计数，避免相差一帧。
- `绝对帧 = 主时间轴起帧 + Blender 局部帧 - 1`。
- `局部秒数 = (局部帧 - 1) / fps`；主时间轴秒数为 `绝对帧 / fps`。
- 主工程和序列必须使用同一实际帧率；29.97 与 30 不能混用。
- 对 30000/1001，应输入足够精度的 `--fps 29.97002997002997`，并核对 manifest。
- 非整数帧率由 Blender 的 `fps / fps_base` 表达；不要只读取整数 `fps`。
- 若 AE 在全高画面中放置较矮的 3D 通道，先扣除通道位置偏移再换算保护区。
- 例如通道顶边位于主合成 y 偏移处，通道内 y = 主合成 y - 该偏移。

## 建模：弯曲必须改变轮廓

- 使用有纵向细分的四边形网格，长宽比跟随纸张扫描图，避免把印字压扁。
- 纵向弓起、横向轻扭、局部卷角分别作用；不要仅弯一张平面法线。
- 示例使用 8×24 网格、曲面平滑、形态键、Solidify 和小幅 Bevel。
- 长边与卷角应在相机下有可见轮廓变化；仅增加顶点数不等于有立体感。
- 薄边可适度加强以便读出受光，但不要厚成木板或金属片。
- 厚度、凹凸距离和灯光尺度与场景单位一起调整，不能只改纸的整体缩放。
- 不同纸张可以有不同弯曲相位，避免所有正面平行排队。
- 确定性的艺术指导轨迹适合严格帧点；若用 Cloth，应缓存并记录缓存版本。

## UV、纸面与正反面

- 优先使用生成或拍摄的正视纸纹、墨迹与印章材质，不用程序条纹冒充最终纸画。
- 示例没有 `--texture` 时只生成可编辑的米色纸、红边和抽象墨条占位。
- 使用 `--texture` 后会读取图像长宽比，并把图像打包进输出 blend。
- 外缘可能有黑角、扫描底色或透明杂边，UV 可裁入 0.02–0.98 后由网格定义边缘。
- UV 裁入是清除扫描外框，不能拿来补救错误的纸面长宽比。
- 正面要保留黑墨、朱砂和纸底三种层级；反面可降低印刷对比并略透印。
- 至少一张主纸应朝向镜头、处于焦平面，不能所有大纸都显示发白背面。
- 纤维用低强度、细尺度、方向性凹凸；凹凸不是透明度，也不是金属高光。
- 纸面粗糙度较高，边缘通过侧光读出；避免大块镜面反射洗掉印刷。
- 实际成片中辨认墨迹和弯边，比材质节点数量更重要。

## 三层深度与景深

- 近景：少量大纸从画幅边缘经过，允许部分出画，有适度景深模糊。
- 主体层：至少一张大纸清楚显示纹理、卷边和正面印刷。
- 中远景：数量较多、尺寸较小，深度与旋转错开，爆散后降低视觉密度。
- 用位置 Z 变化产生真实透视尺寸变化，不能只把所有纸同比例放大。
- 固定镜头便于和 AE 对齐；有横移或滚转时，应重新审查每个保护区。
- 对焦距离在爆散期间由阵列深度转到主纸，随后保持稳定的小幅变化。
- 示例用 50 mm 镜头、f/1.8 展示不同清晰度；它们是起点，不是通用成片参数。
- 如果所有大纸都模糊，优先修正焦点和主体深度，而非提高锐化。
- 如果画面像多层贴纸，检查曲面轮廓、受光、遮挡、透视变化是否同时存在。

## 聚集、四帧爆散、慢漂

| 阶段 | 需要看见的变化 | 常见失败 |
|---|---|---|
| 较松规则阵 | 有秩序且能分辨间距 | 首帧已经紧密，缺少聚集过程 |
| 向心聚集 | 半径和纸间距持续缩小 | 只改变透明度，没有位移 |
| 短暂停顿 | 紧阵保持，建立预期 | 停顿期间仍无规则抖动 |
| 四帧爆散 | 明显 Z 前冲、外扩、旋转与短拖影 | 平面小纸四散，尺寸几乎不变 |
| 慢漂 | 速度骤降但姿态持续变化 | 完全冻帧，或一直高速飞走 |

示例把爆散首帧记为 B，四个输出采样为 B、B+1、B+2、B+3。
首末采样之间是三个帧间隔；不要把这个定义与四个帧间隔混为一谈。
慢漂从 B+4 开始，纹理恢复清楚；爆散使用的强模糊不能长时间覆盖主纸。
更换 fps 后，固定四帧的秒数会变化；若要保持冲击时长，应重新决定采样帧数。
示例的聚集与停顿根据总帧数或 `--burst-frame` 推导，不包含特定作品的绝对剧情帧点。
慢漂使用独立的小幅平移、XYZ 旋转和弯曲变化，不声称未经测量的固定速度倍率。
若作品要求爆发后速度为 1/20，应对比同一物体的每帧投影位移，明确测量区间。

## 人物与文字保护区

- 用归一化矩形定义需要保持干净的区域，原点是通道左上角，范围 0–1。
- CLI 支持重复 `--protected-rect NAME:X0,Y0,X1,Y1`，名称必须唯一。
- 保护框用于审查，不会自动加遮罩或把所有纸夹到上下两条边线上。
- 首先调整聚集中心、爆散路径与 Z 深度，使纸自然绕开重要区域。
- 轨迹修改应连续衰减或重做邻近关键帧，不能只修有问题的一张 PNG。
- 保护脸不等于完全禁止前景遮挡：手、袖口或画面边缘可以承担空间关系。
- 具体可遮挡区域应来自当次构图，不能把示例坐标直接当作角色脸的位置。
- `--strict-protection` 在发现任意非零交叠后抛出错误，保留证据，不偷偷消除交叠。
- 启动参数加 `--python-exit-code 1`，让 Python 错误传递为后台进程的非零退出码。

## 必须有两种全帧审查

第一种是几何投影。逐帧设置时间，取得 evaluated depsgraph，再读取 evaluated mesh。
投影必须包括形态键、细分、厚度、变形和最终世界矩阵，最后释放临时 mesh。
只投影原始 `obj.data.vertices` 会漏掉卷角、厚边以及经过修改器的真实范围。
包围框交叠是保守风险提示，不能直接等同于真实像素遮挡。
还应记录是否有顶点到达相机背后，防止近景穿镜头产生翻转或巨型多边形。

第二种是实际渲染 Alpha。逐个解码最终 PNG，检查尺寸、位深、颜色类型与透明值。
景深和运动模糊会超出几何投影，所以几何零交叠不能替代 Alpha 检查。
每个保护区至少记录 alpha 最大值和超过选定阈值的像素数；阈值应写进报告。
Blender 图像缓冲区从左下开始，保护框从左上开始，转换错误会造成假通过。
透明背景应包含 alpha=0；有纸的帧应有非零 alpha；空前奏帧则允许全透明。
三帧抽查只证明三帧可用。最终交付必须检查完整输出序列，不可把抽查称作全帧通过。
示例每次投影检查全时间轴，Alpha 审查只覆盖 `--render-frames` 实际输出的帧。
`manifest.json` 明确记录覆盖数量，只有 `--render-frames all` 才可能覆盖全部帧。

## 透明交付与 AE 整合

- 输出 PNG：RGBA、16 bit、Film Transparent；PNG 文件使用 straight / unassociated alpha。
- Blender 内部像素可能采用关联 Alpha，不要据此把导入的 PNG 重复预乘。
- AE 将完整 PNG 序列解释为正确 fps 和 Straight Alpha，并检查首末帧对应关系。
- 两段 AE 合成接同一序列时，第二段从前一段已用帧数继续，不能重放帧 1。
- 角色、纸和背景需要统一模糊、反相或色变时，把纸放进同一个光学预合成内。
- 可将近纸放在清晰角色上方、主文字下方；最终顺序按实际遮挡意图确认。
- 单看透明通道不能确认最终阅读性，必须重新渲染实际 AE 合成连续帧。
- 逐帧看聚集末端、四帧爆散、慢漂首帧、色变前后和段落拼接，不能只看中点。
- 特别检查纸是否随整幅画面一起反相、是否在白底露黑边、是否有一帧尺寸跳变。
- 如另交 ProRes 4444，编码前先确认序列无缺帧；编码后解码验证真实 alpha 与帧数。
- 不以文件扩展名、编码器名称或导出成功提示代替透明通道的实际检查。

## 运行示例与输出

只在新建后台进程运行；脚本拒绝前台 GUI、缺少 `--factory-startup` 或加载了旧 blend 的进程。
脚本清场仅发生在这个独立进程，不关闭或控制用户正在使用的 Blender 窗口。
它拒绝覆盖已有同名 demo blend 或纸张 PNG；重试使用新输出目录。

```bash
blender --background --factory-startup --python-exit-code 1 --python scripts/blender_paper_demo.py -- --output-dir ./work/paper-demo --fps 30 --frames 72 --burst-frame 28 --render-frames 18,31,48 --resolution-percent 25
```

添加 `--texture ./inputs/paper_scan.png` 使用自己的纹理；不添加时无需任何外部图片。
添加 `--width 1920 --height 816` 可改变画幅；保护框仍以该输出通道为坐标基准。
示例保护参数：`--protected-rect title:0.01,0.01,0.15,0.1 --strict-protection`。
正式输出改为 `--render-frames all --resolution-percent 100`，并逐帧复核实际合成。
输出包括可编辑 `paper_demo.blend`、`renders/paper_XXXX.png`、全帧投影报告和 manifest。
manifest 含时序、帧率、帧映射、渲染 Alpha 结果与文件哈希，便于后续冻结版本。
最终验收依赖实际画面：正面印刷可读、近中远清楚、快慢有区分、主要阅读区安全。
