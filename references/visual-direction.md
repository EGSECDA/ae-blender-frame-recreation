# 素材与演出设计

## 先辨认参考的机制

把“像不像”拆成可修改的因素：镜头起止帧、冲击长度、速度变化、文字透视、视觉重心、色块比例、遮挡关系、模糊和色彩切换。题材转换不要求复制原角色，但要保留用户重视的运动机制。不要把所有场景统一做成同一种缓慢推近。

对同一段同时保留三类证据：连续帧序列、关键参数与正常速度观看记录。连续帧能揭示一帧的色变和几帧内的反弹；正常速度判断节奏、可读时间和视线能否跟上。只有静态图好看不代表演出成立。

## 图像模型的任务边界

使用当前可用的图像生成/编辑工具制作缺少的位图。优先让模型生成可供分层处理的素材，后续 AE 文字保持原生。若工具不可用，明确缺项，不能用临时占位图宣称完成生成。

为每张素材记录用途、尺寸、人物焦点、裁切安全区、透明/背景方式和来源。不要把工具返回的整段图像 Base64 写入日志或技能文件。把实际输出复制到用户项目的素材子目录后再引用。

### 角色原画

- 先决定是全身站位、半身对白、眼部特写还是朝镜头施法。不要把同一张立绘无止境放大来兼任所有镜头。
- 对白素材需保持头顶、侧发和手臂可用余量；施法镜头需明确手势、视线和力量方向，给符阵/文字留出空间。
- 若使用绿幕背景，要求背景均匀、不要绿色光晕、人物不要穿同色衣物；实际放进 AE 抠像检查发丝、透明薄纱、绿色溢色和边缘噪点。最终采用哪种抠像方式取决于真实素材。
- 记录脸部/眼部在源图中的坐标，用于取景；缩放后要按实际窗口尺寸再检查，不能复用另一张图的锚点。

提示词结构示例：

> 指定角色与画风；明确半身/全身、朝向和表情；描述与当前镜头一致的动作；说明人物落在画面哪一侧、另一侧留白；给头发和袖口保留余量；背景或透明方式；不生成 UI 标题和对话文字。

### 场景与分层原画

先明确镜头会移动哪些几何体，再生成能铺在场景中的背景、天空、地面或远景画。人物、环境、前景有独立素材时，可在 AE 做有限视差；这类景片运动要与真实 Blender 镜头区分清楚。

大型幻影适合作为低对比背景：放在主体后，降低局部对比，避免眼睛、鼻子等高对比细节与主标题争抢注意力。配色变化应作用于同一演出整体，不能让新增前景素材在倒色时突然保持旧颜色。

### 纸张等近景材质

纹理要能铺到网格上：正视、均匀照明、边缘完整、没有手和桌面投影。纸纤维、淡折痕、墨迹渗化、朱印可由图像模型生成；明显的拍摄阴影不宜直接当作 Albedo。

生成后先看原图再接材质。纸边若含背景颜色，用 UV 在纹理内安全取样或重新生成干净材质；不要把黑角贴进每张符纸。字迹作为质感可以保留，但必须准确读出的标题、日期和台词继续用 AE 原生文字。

## UI 与三维字的层次

设计主标题、次标题、微文案、标尺/辅助线的尺度关系。每个装饰应表达状态、身份、方向或节拍；删除没有作用的重复圆圈和切片。

近处主词、侧面厚度、远处小字可以共享父级运动，但小字需要单独的可读区。渲染入场结束帧和持续推进的最后一帧；透视推进可能让初始安全的小字离开屏幕。

文本与底板一起三维变换时，先放入同一个二维预合成再将预合成设为三维，可避免两层几乎共面却互相闪烁。只有需要真正穿插的部件才分为独立深度。

## 高潮的节奏与空间

一个可迁移的演出结构是：力量预备 → 1–几帧冲击 → 规则集合 → 短停 → 几帧爆散 → 慢动作。实际时长从参考或音乐确定，不强制所有高潮使用同一组数字。

纸张至少考虑三种阅读距离：远层表达结构，中层展示材质，近层掠过镜头并虚焦。不要让全部纸张同样清晰、同样尺寸、同样速度。保证中层至少有一张纸在慢动作阶段具有足够像素显示材质。

前景可以经过袖子或手部以建立前后关系；脸和主标题需要可读时则规划轨迹避让。用真实相机投影和最终 Alpha 检查，不能把“物体中心没碰到脸”当作安全。
